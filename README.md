# Nocture — Studio Viewer

An architectural-visualisation virtual tour of **Nocture**, a premium ~4 × 7 m
coffee bar & audiophile listening room. The space is modelled and rendered with
a real path tracer (Blender Cycles) and presented through an interactive
"studio viewer" web UI.

> Dark green tile, dark terrazzo, warm brass, oak slats, a La Marzocco-style
> espresso machine and a wall of studio monitors — a refined coffee bar with an
> audiophile soul.

---

## How it works

There are two halves to this project:

### 1. The render pipeline — `blender/`

The entire room is built **procedurally in Python** and rendered with
**Cycles** (path-traced, OpenImage-denoised). No manual modelling — every wall,
the bar, the espresso machine, the speaker wall, the seating and the lighting
are generated by code, so the whole scene is reproducible and tweakable from one
script.

| File | Purpose |
| --- | --- |
| `blender/nocture_scene.py` | The scene: geometry, materials, lighting, cameras. Renders one camera per invocation. |
| `blender/render_all.sh` | Render all 7 cameras into an output folder. |
| `blender/sync_scenes.sh` | Copy the newest render per camera into `public/scenes/` (prefers `v3 > v2 > v1`). |
| `blender/assets/` | Real scanned PBR textures + HDRI pulled from open sources. |

Render a single hero shot:

```bash
pip install bpy==4.5.10           # Blender as a Python module (Python 3.11)
python3 blender/nocture_scene.py -- \
  --camera counter_hero --res 1920x1080 --samples 256 --out /tmp/hero.jpg
```

Render the whole set:

```bash
bash blender/render_all.sh 1920x1080 256 blender/out/final
bash blender/sync_scenes.sh
```

**Cameras:** `counter_hero`, `entrance`, `equipment`, `brew_lab`, `seating`,
`audiophile`, `operator`.

Realism techniques layered in so far:

- Path-traced global illumination + OpenImageDenoise
- Procedural PBR materials: dark terrazzo (Voronoi chips), glazed green stack
  tile, brushed metals, glass
- **Real scanned hardwood** (2K diffuse + bump + roughness) box-projected onto
  every oak surface
- **HDRI image-based lighting** at low strength for believable highlight
  break-up on chrome / brass / glass / terrazzo
- Edge bevels on every primitive, a pointiness-driven "appliance black" for the
  espresso machine, recessed speaker cones, a bmesh leafy plant
- Warm 2700 K cove + toe-kick LED, ceiling track spots, slatted oak ceiling

### 2. The viewer — `src/`

A Vite + React app that presents the renders as an interactive studio viewer
(the layout in the design mockup): floorplan, zone list, scene hero with
drag-to-look / scroll-to-zoom and clickable hotspots, an equipment inspector,
lighting modes + intensity, a material palette, a mood gallery and a scene
filmstrip.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build into dist/
```

Hero images live in `public/scenes/<camera>.jpg` and are produced by the render
pipeline above.
